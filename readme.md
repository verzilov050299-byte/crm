# BizCRM

Простая CRM для автосервиса на **Flask**.  
Воронки и сделки — по логике **Bitrix24 CRM**.

## Локальный запуск

```bash
cd ~/Desktop/BizCRM
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python app.py
```

Компьютер: http://127.0.0.1:5001  
Телефон в той же Wi‑Fi: `http://IP-компьютера:5001`

## Демо-вход

Пароль совпадает с логином.

| Логин | Роль |
| --- | --- |
| `admin` | Администратор |
| `director` | Руководитель |
| `receiver` | Мастер-приёмщик |
| `painter` | Маляр |
| `body` | Жестянщик |
| `tire` | Шиномонтажник |

## Почта: регистрация и приглашения

1. Скопируйте `.env.example` → `.env` и заполните `MAIL_*`.
2. Пример для Яндекса: `MAIL_SERVER=smtp.yandex.ru`, порт `587`, пароль приложения.
3. Администратор: меню **Сотрудники → Пригласить** — письмо с логином и паролем.
4. Гость: страница **/register** — сам создаёт доступ, письмо приходит на почту.
5. Пока SMTP не настроен, письма пишутся в `instance/mail.log` (можно проверить локально).

`SITE_URL` — адрес вашего сайта, он попадает в письмо.

## Как выложить на сайт (Render)

Чтобы CRM открывалась у всех, а не только на вашем Mac:

1. Залейте проект на GitHub.
2. На [render.com](https://render.com) создайте **Web Service** из репозитория.
3. Добавьте **PostgreSQL** и скопируйте `DATABASE_URL` в переменные сервиса.
4. Переменные окружения:

| Переменная | Пример |
| --- | --- |
| `SECRET_KEY` | длинная случайная строка |
| `DATABASE_URL` | из Render Postgres |
| `SITE_URL` | `https://ваш-сервис.onrender.com` |
| `MAIL_SERVER` | `smtp.yandex.ru` |
| `MAIL_PORT` | `587` |
| `MAIL_USERNAME` | ваша почта |
| `MAIL_PASSWORD` | пароль приложения |
| `MAIL_FROM` | та же почта |
| `ALLOW_PUBLIC_REGISTER` | `1` или `0` |

5. Start Command уже в `Procfile`: `gunicorn wsgi:app --bind 0.0.0.0:$PORT`
6. После деплоя откройте `SITE_URL`, войдите как `admin` / `admin` (или сразу пригласите себя по почте и смените пароль).

Похожий путь работает на Railway / Fly.io: тот же `Procfile`, те же переменные.
